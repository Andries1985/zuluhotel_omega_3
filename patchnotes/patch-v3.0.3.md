# Patch Notes - v3.0.3
**Zuluhotel Omega 3 | Beta Shard**

## What Changed

Patch 3.0.3 is a broad parity and stability pass focused on combat behavior, class/race restrictions, teleporters, identification flow, and world interaction consistency.

Players should notice cleaner combat outcomes, improved mount/character lifecycle behavior, more reliable item identification flow, and expanded teleporter/admin maintenance tooling.

## Combat, Skills, and Spell Behavior

- Restored and tuned multiple combat/hitscript paths for parity (including critical stamina-hit support).
- Updated slayer/elemental/on-hit behavior definitions and related combat descriptors.
- Applied fixes across several spells/skills to improve target validation, safety filtering, and consistency.
- Improved party/pet/no-PK safety handling paths involved in harmful effects.

## Class, Race, and Character Lifecycle

- Updated class/race handling and related restrictions for parity behavior.
- Starting equipment flow and related class setup rules were revised.
- Mountstone and death/logoff handling were tightened to prevent incorrect retained mount states.
- Added follow-up fixes for title/class-related world interactions.

## Item, Identification, and Utility Updates

- Added follow-up fixes for item identification behavior and merchant identify flow.
- Included additional world/item updates (including recall rune/heating stand support).
- Updated container/item descriptor behavior where needed for consistency.

## Teleporters and World Tools

- Expanded teleporter include/system coverage.
- Added admin cleanup tooling for dungeon teleporters via `.deletedungteles`.
- Continued maintenance updates across area tools and related region/world scripts.

## Townstones and Systems Follow-up

- Townstone election/startup/admin command paths received another maintenance pass.
- City membership/treasury/admin support flows were refined for reliability.
- Additional parity fixes were applied across supporting systems and configs.

## Quality-of-Life and Testing Support

- Added animated graphics test command support and related animation test updates.
- Refreshed command synopsis/config coverage for the current command set.
