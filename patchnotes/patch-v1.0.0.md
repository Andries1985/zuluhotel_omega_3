## What Changed

Patch 1.0.0 established the first full Omega 3 gameplay baseline. It introduced the new core package set and rolled in broad system coverage for housing, boats, containers, merchants, banking, crafting, jobs, keys, and spawn/content support.

Players should notice a much wider set of usable systems, more complete item and crafting behavior, and stronger support for shard gameplay features compared to earlier baseline states.

## Gameplay Systems

- Added major core package coverage to support live shard play.
- Introduced/expanded housing and boats support.
- Added secure container, key, and storage-area support.
- Expanded merchant and banker behavior with stability fixes.

## Crafting and Items

- Added a large set of new craftable items and deed-based content.
- Expanded tinkering, blacksmithing, tailoring, and carpentry support.
- Updated container interactions, lock/key behavior, and related item flows.

## World and NPC Support

- Added/expanded spawn content and NPC package support.
- Included mount-related and animation/content updates in the baseline import.
- Applied multiple early bugfix passes across core shard scripts.

## Tools and Project Base

- Imported and aligned foundational project files for the shard branch line.
- Added baseline changelog tracking and package-level update support.
